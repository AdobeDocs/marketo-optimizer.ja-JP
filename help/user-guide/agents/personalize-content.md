# ペルソナ別にメールコンテンツをパーソナライズ

_Content Personalization_ スキルは、メールをペルソナベースのデータに基づいたバリエーションに変換するので、各オーディエンスに対して個別のメールを作成する必要はありません。 イベントの後に1つのメッセージを送信する代わりに、スキルはオーディエンスを[派生ペルソナ ](../audiences/personas.md) コホートに解決し、インサイトを表面化し、パーソナライズされたバリエーションを生成します。 あらゆるバリエーションは、ひとつの電子メール内に条件付きコンテンツとして保存されるため、ジャーニーの送信時に、各自がペルソナに一致するバージョンを自動的に受信します。

* **スキル** - `content-personalization`
* **呼び出し** - [ チャットインターフェイス ](./chat-interface.md)から、新しいメールのターゲットオーディエンスを記述するか、プログラムツリー](../marketing/email-channel.md#personalize-analyze)の下書き[ メールの&#x200B;_詳細_ メニューから&#x200B;**[!UICONTROL メールのパーソナライゼーション]**&#x200B;または&#x200B;**[!UICONTROL メールの分析]**&#x200B;を選択します
* **から読み取り/**&#x200B;に書き込む – [!DNL Marketo Optimizer]

## 主要概念 {#key-concepts}

| 用語 | 定義 |
| --- | --- |
| **ペルソナコホート** | _CXO/EVP_&#x200B;や&#x200B;_個人貢献者_&#x200B;など、[派生ペルソナ ](../audiences/personas.md)を共有するユーザーのグループ。 |
| **セグメント** | ペルソナ、業界、エンゲージメント層など、あらゆる基準で定義された人々のグループ。 ペルソナコホートとは、共有された派生ペルソナによって特別に定義されたセグメントのことです。 |
| **ターゲットグループ** | オーディエンスのことです。 スキルは、それを一致するペルソナコホートに解決します。 |
| **Insight** | 自社データを基に、ペルソナコホートに最適なメッセージ、ポジショニング、トーンを決定します。 |
| **バリアント** | 1つのペルソナコホートに対して生成され、パーソナライズするために選択したメールセクションのパーソナライズされたバージョン。 |
| **AI パーソナライズされた電子メール** | 各バリエーションを[条件付きコンテンツ ](../content/conditional-content.md) ブロックとしてバンドルする、1つの保存済み電子メール。 |
| **メール監査** | ターゲットグループの各セグメントに対する既存の電子メールのレビュー。パーソナライズする前に、各ペルソナの共感を呼ぶ要素と、改善すべき点を把握しましょう。 |

## 前提条件 {#prerequisites}

* [!DNL CX Coworker]が有効になっている[!DNL Marketo Optimizer]へのアクセス。
* データ内で[派生ペルソナ ](../audiences/personas.md)が解決されました。 スキルは、ペルソナコホートを構築するためにこれらの分類に依存しています。 カスタムペルソナのサポートは、今後のリリースで予定されています。
* インサイトに十分な履歴データ： ペルソナのコホートに関するインサイトが入手できない場合、スキルはデータが不十分であることを示し、そのペルソナの一般的なベストプラクティスにフォールバックします。
* プログラム内の[電子メールテンプレート ](../content/templates.md)または既存のドラフト [電子メール ](../marketing/email-channel.md)。
* パーソナライズされた電子メールの配信に使用される&#x200B;_メール送信_ アクションノードを含む[人物ジャーニー](../marketing/person-journeys.md)。

## テンプレートからのメールの作成とパーソナライズ {#create-personalize-from-template}

このフローでは、新しい電子メールを作成し、同じ会話でパーソナライズします。

1. **チャットインターフェイスで`/content-personalization` スキル**&#x200B;を呼び出します。[!DNL Coworker]

1. **コンテンツを提供します。**

   コンテンツ概要をアップロードするか、自然言語でコンテンツを説明します。

1. **テンプレート**&#x200B;を[ テンプレート ](../content/templates.md) ライブラリから選択します。

1. **ドラフトをレビューします。**

   [!DNL Coworker]さんがコンテンツをテンプレートにマッピングし、下書きのメールを生成します。 基本的なテキスト編集はインラインで行うことができます。

   >[!WARNING]
   >
   >オーサリング時にインラインで使用できるのは、基本的なテキスト編集のみです。 高度な編集を行うには、電子メールを保存して、[ ビジュアルデザインスペース ](../content/email-authoring.md)で開きます。

1. **ターゲット グループ**&#x200B;を自然言語で説明します。

1. **解決済みのペルソナ コホートを確認**。

   [!DNL Coworker]はデータを検査し、説明に一致するペルソナ コホートを、それぞれのカウントで返します。 ターゲットグループの説明を変更し、必要に応じてもう一度試してください。

1. **ターゲットグループを確認**。

   次に、[!DNL Coworker]は、解決された各ペルソナ コホートのインサイトを取得します。

1. **件名や本文セクションなど、パーソナライズするセクション**&#x200B;を選択し、生成されたバリエーションを確認します。

   バリエーションが適切に表示されない場合は再生成します。 ペルソナコホートの数は固定されていません。 ターゲットグループとデータによって異なります。

1. **電子メールを保存**。

   あらゆるバリエーションは、個別のメールではなく、1つのAI パーソナライズされたメールに保存されます。

## 既存の電子メールの分析 {#analyze-existing-email}

_分析_ ツールは、下書きメールでのみ使用できます。 メールが公開された後は、変更できません。 プログラムツリーで、_詳細_ アイコン （**...**）をクリックします [ メール ](../marketing/email-channel.md#manage-emails)の下書きの横に移動し、**[!UICONTROL メールを分析]**&#x200B;を選択します。

![ プログラム ツリー電子メール詳細メニュー](../marketing/assets/email-tree-more-menu.png){width="400"}

メール監査を実行するには：

1. **ペルソナに関して、パーソナライズするターゲットグループ**&#x200B;を説明します。

   例：_マーケティングの役割の人物_&#x200B;または&#x200B;_リーダーシップ機能の人物_。

1. **メール監査を確認します。**

   [!DNL Coworker]は、説明をペルソナセグメントに解決し、各セグメントを一覧表示する&#x200B;**Email audit** カードを表示し、その後、各セグメントに対してメールを確認して、何が共感し、何を改善するかを強調します。

1. [!DNL Coworker]さんが次に何をすべきか尋ねます。**[!UICONTROL セクションごとの監査]**&#x200B;および&#x200B;**[!UICONTROL このメールのパーソナライズ]**&#x200B;を参照してください。

1. 「**[!UICONTROL セクションごとの監査]**&#x200B;を参照」を選択して、ペルソナセレクターと各セクションの具体的な推奨事項を含む&#x200B;**_メール分析_** ビューを開きます。

   各セクションには推奨される変更回数が表示され、各ペルソナには`4 recommendations for SVP/VP`などの推奨回数が表示されます。 また、チャットに&#x200B;_personalize_&#x200B;と入力して、レコメンデーションを直接適用することもできます。

1. 監査から、**[!UICONTROL この電子メールをパーソナライズ]**&#x200B;を選択して、インサイトを適用し、バリエーションを生成します。

   次の節「[_既存の電子メールをパーソナライズする_](#personalize-existing-email)」を参照してください。

## 既存のメールのパーソナライズ {#personalize-existing-email}

プログラムツリーの下書きメールの&#x200B;_詳細_ メニューから「**[!UICONTROL メールをパーソナライズ]**」を選択するか、[ メール監査](#analyze-existing-email)から続行して、既に作成したメールをパーソナライズします。

1. **解決済みのペルソナ コホートを確認します。**

   [!DNL Coworker]はデータを検査し、説明に一致するペルソナ コホートを、それぞれのカウントで返します。 ターゲットグループの説明を変更し、必要に応じてもう一度試してください。

   メール監査からこの手順に到達した場合、[!DNL Coworker]は監査インサイトから直接続行されます。

1. **件名や特定のコンテンツのセクションなど、電子メールのプレビューでパーソナライズするセクション**&#x200B;を選択して、確認します。

1. **生成されたバリエーションを確認します。**

   また、CXO （顧客体験管理）など、業種によって大きな違いがあります。 [!DNL Coworker]さんが、件名、見出し、本文、および&#x200B;**[!UICONTROL プレビュー]** オプションを含む、**[!UICONTROL パーソナライズされたバリエーション]** グリッド、ペルソナコホートごとに1枚のカードを提示します。

   カード上の&#x200B;_情報_ アイコンを選択すると、そのバリエーションのinsight（そのベースとなるペルソナと、その情報を提供したエンゲージメント insight）が表示され、必要に応じてバリエーションが再生成されます。

   ペルソナ別にグリッドをフィルタリングできます。

1. **セットを保存します。**

   「**[!UICONTROL 保存]**」をクリックして確認します。 [!DNL Coworker]は、電子メールがAI ライブラリで利用可能になったことを確認し、元の電子メールに変更を適用するかどうかを尋ね、その後、元の電子メールを更新します。

## ジャーニーの出力と使用状況を保存 {#saved-output}

どのフローから開始しても、パーソナライゼーションは、AI ライブラリに保存された&#x200B;_AI パーソナライズされた電子メール_&#x200B;を1通だけ生成します。 このメールには、ペルソナがキーを設定した[条件付きコンテンツ ](../content/conditional-content.md) ブロックが含まれています。 セクションを編集するには、[ ビジュアルデザインスペース ](../content/email-authoring.md)でセクションを開き、各ペルソナ鍵ブロックがどのように解決するかをプレビューするには、**[!UICONTROL コンテンツをシミュレート]**&#x200B;します。

ジャーニーでメールを使用するには、[ メール送信ノード ](../marketing/action-nodes.md)を追加し、**[!UICONTROL AIによってパーソナライズされたメールを使用]**&#x200B;を選択します。

![ アクションを実行 – メールを送信 – AIでパーソナライズされたメールを使用](../marketing/assets/person-action-node-email-source-personalized.png){width="450"}

次に、保存されたメールを選択します。 通常どおり、設定ルールとビジネスルールをノードに適用します。

## 実行時の動作 {#run-time-behavior}

ジャーニーでは、AIでパーソナライズされた電子メールを1つ選択するだけで、オーディエンスごとに1つのバリエーションを選択することはできません。 ジャーニーが実行されると、メールは各受信者のペルソナに一致するバリエーションに自動的に解決されます。 受信者ごとにバリエーションを選択することはできません。

## 制限事項 {#limitations}

| 制限事項 | 詳細 |
| --- | --- |
| **カスタムペルソナ** | まだサポートされていません。 このスキルでは、すぐに使える[派生ペルソナ ](../audiences/personas.md)のみからペルソナコホートを分類します。 |
| **インサイトに対するデータが不十分です** | データがペルソナのコホートに対してinsightをサポートしていない場合、そのペルソナの一般的なベストプラクティスにフォールバックするとスキルに記載されています。 |
| **オーサリング中のインライン編集** | テンプレート ](#create-personalize-from-template)から電子メールを作成およびパーソナライズする[場合は、基本的なテキスト編集のみがインラインで使用できます。 詳細な編集には、[ ビジュアルデザインスペース ](../content/email-authoring.md)が必要です。 |
| **開始点が必要** | メールをパーソナライズするには、テンプレートまたはプログラム内の既存のドラフトメールが必要です。 |
