# インテント設定

単一の標準化された一連のアクティビティの重みづけは、顧客をまたいでは機能しません。 真の購買意欲を示すシグナルは、企業によって異なります。 インテントモデルを設定してアクティブ化し、重要な内容（フォームへの入力がメールのクリック以上の場合など）を指定します。グローバルなデフォルトをひとつ継承する代わりに使用します。

**[!UICONTROL インテント設定]** パネルツールは、各リードインテントアクティビティが個人のインテントスコアに対してどの程度カウントされるかを制御します。 これは、インテントスコアリングに設定可能な唯一の情報です。 コンテンツの関連性、減衰、しきい値などのその他の要因は、システムで管理されます。 これは、[ インテント設定スキル ](../agents/intent.md#configure-model)を通じて使用できます。

共同作業者[ チャットインターフェイス ](../agents/chat-interface.md)から2つの方法のいずれかを使用してパネルを開きます。

* `/intent-configuration` コマンドを入力します。
* **[!UICONTROL +]**&#x200B;をクリックし、**[!UICONTROL エージェントスキルを使用]**&#x200B;を選択し、**[!UICONTROL インテント]** タブを選択してから、**[!UICONTROL インテント設定]**&#x200B;をクリックします。

![ チャットインターフェイスからインテント設定パネルを開いた](./assets/intent-configuration-panel.png){width="700" zoomable="yes"}

## モデルリストビュー

パネルに表示されているインテントスコアの重み付けは&#x200B;**[!UICONTROL で、タイトルの下にモデルの合計数、名前で絞り込む検索フィールド、並べ替え可能なテーブルが表示されます。]**

| 列 | メモ |
| --- | --- |
| [!UICONTROL 名前] | 並べ替え可能、デフォルトの並べ替え |
| [!UICONTROL ステータス] | _[!UICONTROL アクティブ]_ （緑のドット）、_[!UICONTROL ドラフト]_ （オレンジ色のドット）、_[!UICONTROL アーカイブ]_ （灰色のドット） |
| [!UICONTROL 作成日] | カーソルを合わせた日付を短縮 |
| [!UICONTROL 最終更新日] | カーソルを合わせた日付を短縮 |
| [!UICONTROL 最終更新者] | 切り捨てられたユーザー名、カーソルの位置にフルネーム |

一度に&#x200B;_[!UICONTROL アクティブ]_&#x200B;にできるモデルは1つのみです。これは、スコアリングを促進するモデルです。 他のすべてのモデルは、_[!UICONTROL ドラフト]_ （編集中、まだ公開中）または&#x200B;_[!UICONTROL アーカイブ]_ （旧&#x200B;_[!UICONTROL アクティブ]_ モデル、新しいモデルがアクティブ化されると自動的に格下げ）の状態にあります。

行をクリックして、モデルの詳細ビューを開きます。

## モデル詳細ビュー

詳細ビューには、モデル名、ステータスバッジ、最後に保存されたタイムスタンプ、および&#x200B;**[!UICONTROL インテントスコアの重み付け]**&#x200B;とモデル名を表示するパンくずリストに戻るには、クリックします。

詳細ビューには、バイヤーの購買意欲に関するアクティビティと、各アクティビティが個人のインテントスコアに影響を与える重要度レベルが一覧表示されます。 アクティビティカタログは固定され、レベルのみが変更できます。 これらのレベルは独立しています。合計を合計する必要はありません。 一度にアクティブにできる重み付けモデルのバージョンは1つだけです。 変更を加えるには、現在のバージョンを複製し、コピーを編集します。

![ アクティブなインテント モデルの詳細ビュー](./assets/intent-configuration-model-detail.png){width="550" zoomable="yes"}

検索フィールドは、アクティビティ行を名前でフィルタリングします。 テーブル自体：

| [!UICONTROL  インテント アクティビティ ] | [!UICONTROL AI候補] | [!UICONTROL 重み付け] | [!UICONTROL  リセット ] |
| --- | --- | --- | --- |
| たとえば、「商談に追加」、「フォームに入力」、「電子メールをクリック」、「リンクをクリック」、「電子メールを開封」、「Web ページにアクセス」、「ウェビナーでの質問」、「ウェビナーでのアセットのダウンロード」、「興味深い瞬間」、「ウェビナーでの投票に回答」、「商談を更新」などがあります | 読み取り専用 | ドラフトモデルで編集可能なドロップダウン | **↺** アイコン：この行をAI推奨値にリセットします |

**重み付け層** （AIの推奨列と重み付け列の両方で同じスケール）:

| 階層 | 値 |
| ---| --- |
| [!UICONTROL 重みなし] | 0 |
| [!UICONTROL ささいなこと] | 30 |
| [!UICONTROL 未成年者] | 40 |
| [!UICONTROL 標準] | 60 |
| [!UICONTROL 重要] | 90 |
| [!UICONTROL Vital] | 100 |

![ ドラフトインテントモデルの「商談に追加」アクティビティの値を変更する](./assets/intent-configuration-model-edit.png){width="550" zoomable="yes"}

アクティビティを&#x200B;**[!UICONTROL 重みなし]** （0）に設定すると、スコアが完全に下がります。 現在、この方法を使用すると、システムはデフォルトで&#x200B;**[!UICONTROL メールの購読解除]**&#x200B;を除外しています。

テーブルの上にある&#x200B;**[!UICONTROL すべてを提案にリセット]**&#x200B;をクリックして、すべての行をAIの推奨値に復元します。

### モデルの作成とアクティブ化

新しい重み付けモデルを作成してアクティブ化するには、次の手順に従います。

1. 既存の&#x200B;_[!UICONTROL ドラフト]_ モデルから開始します。

   現在の&#x200B;_[!UICONTROL アクティブ]_ モデルの&#x200B;**[!UICONTROL 複製]**&#x200B;をクリックして、その重みを新しいドラフトに複製することもできます。

1. ビジネスにとって何が重要かを反映させるために、重みを行ごとに調整します。

   例えば、低シグナルのアクティビティを&#x200B;**[!UICONTROL Trivial]**&#x200B;にダウングレードするか、高シグナルのアクティビティを&#x200B;**[!UICONTROL Important]**&#x200B;または&#x200B;**[!UICONTROL Vital]**&#x200B;にアップグレードします。

1. 「**[!UICONTROL 保存]**」をクリックします。

   保存すると、モデルをすぐにアクティブ化するように求められます。

1. アクティベーションを確認。

確認により、新しい&#x200B;_[!UICONTROL アクティブ]_ モデルとなり、以前にアクティブだったモデルが自動的に&#x200B;_[!UICONTROL アーカイブ]_&#x200B;に格下げされます。 一度にアクティブにできるモデルは1つだけです。

### AIが提案した列

AIの「提案」列は、訓練されたレコメンデーションではなく、出発点です。

* 1つのLLM完了呼び出しは、アクティビティごとに1回の呼び出しではなく、テナントのすべてのアクティビティを一度に処理します。

* 各アクティビティについて、モデルはその名前と説明のみを読み取り、B2B バイヤーの行動に関する一般的な知識にもとづいて重み層を選択します。 例えば、**[!UICONTROL フォームに入力]**&#x200B;または&#x200B;**[!UICONTROL 電子メールをクリック]**&#x200B;すると、通常、B2B バイヤーに対してどのようなメッセージが表示されるかを考えてみましょう。 テナントの顧客データ、CRM レコード、過去のエンゲージメントパターンにアクセスできず、現在はテナント固有またはサブスクリプション固有ではありません。

* 出力は、モデル作成時に`IBG_INTENT_ACTIVITY_WEIGHT`に`SUGGESTED_WEIGHT_VALUE`に入力され、その後は静的のままになります。 重み付け列を編集しても更新されません。

* すべてのアクティビティ行には、常に入力済みの推奨値が表示されます。 どれも空白のままです。

ビジネスコンテキストを反映させるために、あらゆる行を確認し、調整します。 提案された値は、調整されたモデルではなく、合理的なデフォルトです。

## モデル上のアクション

ステータスに基づいてモデルを管理できます。

| アクション | 次で使用可能 | 何が起こるか |
| --- | --- | --- |
| **[!UICONTROL 複製]** | アクティブ、ドラフト | 「**[!UICONTROL 複製]**」というタイトルのモーダルを開きます。名前フィールドが事前入力され、**[!UICONTROL キャンセル]**&#x200B;および&#x200B;**[!UICONTROL 複製]** ボタンが表示されます。 確認すると、同じ重みを持つ新しい&#x200B;_[!UICONTROL ドラフト]_ モデルが作成され、詳細表示で直接開きます。 |
| **[!UICONTROL アクティブ化]** | ドラフトのみ（保存の直後のプロンプトとしても提供） | ドラフトを&#x200B;_[!UICONTROL アクティブ]_&#x200B;に昇格し、以前にアクティブだったモデルを&#x200B;_[!UICONTROL アーカイブ]_&#x200B;に自動的に降格します。 |
| **[!UICONTROL 削除]** | ドラフトのみ | 永続的な削除の前に、確認ダイアログを表示します。 このアクションは元に戻せません。 アクティブなモデルは削除できません。 |

ドラフトモデルのみが編集可能なので、通常のワークフローでは、現在の&#x200B;_[!UICONTROL アクティブ]_ モデルの&#x200B;**[!UICONTROL 重複]**&#x200B;をクリックし、ドラフトコピーの重みを調整してから&#x200B;**[!UICONTROL 保存]**&#x200B;をクリックします。 **[!UICONTROL 有効化]** ボタンを使用して、ただちに、または後でアクティベートできます。

## インテントスコアでの重み付け計算

**[!UICONTROL 重み付け]**&#x200B;列には、現在の&#x200B;_[!UICONTROL アクティブ]_ モデルの行から読み取った、毎日のスコアリングで使用される数値が表示されます。 リードのインテントスコアを促進する3つの要素：

1. **ここで設定された重み** （`WEIGHT_VALUE`）は、各アクティビティに対して設定されます。 AIの提案から始まりますが、テナントごとに上書きできます。 _[!UICONTROL Active]_ モデルに関連付けられた行のみが使用されるので、重み付けの変更はコード リリースを必要としません。

1. **コンテンツの関連性**：ここでは設定できません。 アクティビティ関連のコンテンツやアセットからキーワードを抽出し、そのコンテンツがキーワード、製品、カテゴリーにどの程度適合しているかを0から1の間でスコア化します。

1. **頻度**: リードがそのコンテンツとインタラクションした回数。その回数は、個人のエンゲージメント全体の平均値を考慮します。

正式には、エンゲージメントあたり`activity weight × content relevance`で、**7日間の指数減衰**&#x200B;が適用され、平均で&#x200B;**日のスコア**&#x200B;になり、最近のアクティビティが支配的になり、現在の母集団でmin-maxが0～1に正規化され、グループ化されました。

| 最終スコア | 意図レベル |
| --- | --- |
| > 0.6 | 高 |
| > 0.2 | 中 |
| それ以外は | 低 |

### コンテンツの適切さ

Web ベースのアクティビティの場合、システムはアセット URLと関連する会社を検査し、その会社の分類から関連キーワードを導き出します。 例えば、[!DNL Intuit]に関連付けられたURLは、_tax_&#x200B;や&#x200B;_payroll_&#x200B;などのキーワードを表示します。 例えば、[!DNL TurboTax] ページや[!DNL QuickBooks] ページの閲覧などの、リードとそのコンテンツとの実際のエンゲージメントをキーワードと比較して、そのリードがどの特定の製品に関心を示しているのかを判断します。 _[!UICONTROL Interesting Moment]_ （オフラインイベントを含む）などの非web アクティビティの場合、モデルは、アクティビティタイプではなく、オフラインウェビナーのトピックなどの瞬間の説明やコンテンツを評価します。 イベントカテゴリではなくコンテンツが、関連性を決定します。

## 既知の制限事項

現在のインテント設定には、次の制限が適用されます。

* **現在、カスタム アクティビティまたはテナント定義アクティビティはありません。** アクティビティカタログは固定されており、[!DNL Marketo Engage]は唯一の正しい情報源です。 スコアリングするには、アクティビティを[!DNL Marketo Engage]に記録する必要があります。 テナント定義アクティビティの将来の列をスコープ化しています。
* **現在**&#x200B;では、サードパーティのインテントの取り込みはありません。例：[!DNL Demandbase]、[!DNL ZoomInfo]、または[!DNL 6sense]。 このアップデートは、今後のリリースで予定されています。 それまでの回避策は、サードパーティツールでオーディエンスを構築し、そのシグナルのインテントスコアリングをバイパスして、[!DNL Marketo Engage]または[!DNL Marketo Optimizer]に直接プッシュすることです。
* 重み付けパネルまたはインテントレポートから&#x200B;**ネイティブ書き出し**&#x200B;がありません。 レポートの結果を人物リストに変換するプロンプトについては、[ レポートのフォローアップ ](../agents/intent.md#report-follow-up)を参照してください。
